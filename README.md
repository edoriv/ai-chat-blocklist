## AI Chat Blocklist
Community-maintained domains for AI chat / roleplay (incl. NSFW). Source of truth: `lists/domains.txt`.

## Use
- **AdGuard Home:** use `lists/adguard.txt`
- **Pi-hole (hosts):** use `lists/hosts.txt`
- **Pi-hole (regex):** use `lists/pihole-regex.txt`

## Contribute
Open a PR adding/removing domains in `lists/domains.txt`. CI rebuilds outputs.
